AI 论文写作 Skill：安装与使用

thesis-writing-craft 是一个给 AI 编码助手用的论文写作方法库，装进 Claude Code、Codex、Cursor 这类助手后，你说「帮我搭硕士论文大纲」，它就按公开可查的方法来做，并自带成稿自检清单。这个页面讲怎么装、怎么用。

它帮你做什么

  • 搭大纲：先选写作范式（实证 / 实验 / 质性 / 问题对策），再给章节骨架与各章字数配比，附「问题 ↔ 对策」或「假设 ↔ 检验」对照表。
  • 文献：六步检索路线、三遍阅读法、三层筛选漏斗、精读六问、综述四步（收集 → 分类 → 评析 → 整合）与引注规范。
  • 引言与摘要：引言三段式（背景与意义 / 研究现状 / 本文安排）、摘要与引言的分工、关键词怎么选。
  • 方法章：五条硬要求、四类范式各写哪几块，配好坏写法对照。
  • 选题缩小：三层限定法（对象 → 变量 → 场景）+ 三个创新套路，把导师给的大题目缩成能做的题。
  • 成稿自检：每节过三问（读者今天能照着做什么？数字是多少？做错了会怎样？）、事实可回溯、引注以必要为限。

方法全部来自公开来源（高校图书馆指南、高校官方写作范式文件、ACM 经典论文、Elsevier 作者服务），出处逐条标注，可在 GitHub 仓库里逐条核对。

装法一（推荐）：npx skills

本机装有 Node.js 时，用开源工具 vercel-labs/skills 一条命令安装，它会自动识别你装了哪些助手（Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI、Windsurf 等约 80 个目标）并让你选择：

npx skills add blackfishdel/pcpass-notes

也可以只装这一个 skill（指到仓库里的具体目录）：

npx skills add https://github.com/blackfishdel/pcpass-notes/tree/main/skills/thesis-writing-craft

装法二：一键脚本（不需要 Node）

只要本机有 git，用下面这条命令。脚本会自动找已安装助手的技能目录（有几个装几个），也可以在末尾加参数指定目标：

curl -fsSL https://raw.githubusercontent.com/blackfishdel/pcpass-notes/main/skills/install.sh | bash

指定目标的写法（四选一：claude / codex / zcode / agents）：

curl -fsSL https://raw.githubusercontent.com/blackfishdel/pcpass-notes/main/skills/install.sh | bash -s -- claude
参数安装位置适用的助手
claude~/.claude/skills/Claude Code
codex~/.codex/skills/Codex CLI
zcode~/.zcode/skills/ZCode
agents~/.agents/skills/采用 .agents 通用约定的助手

脚本内容就放在仓库的 skills/install.sh，先看再跑也行。卸载 = 删掉对应目录里的 thesis-writing-craft 文件夹。

装法三：手动复制

git clone --depth 1 https://github.com/blackfishdel/pcpass-notes.git /tmp/pcpass-notes
cp -r /tmp/pcpass-notes/skills/thesis-writing-craft ~/.claude/skills/   # Claude Code
# Codex / ZCode 分别换成 ~/.codex/skills/ 与 ~/.zcode/skills/

装法四：让你的 AI 助手自己装

如果你的助手能执行命令（AI 编码助手一般都可以），直接把下面这段话发给它：

请安装一个 skill：把 GitHub 仓库 blackfishdel/pcpass-notes 里的
skills/thesis-writing-craft 目录克隆下来，复制到你的技能目录
（Claude Code 是 ~/.claude/skills/，Codex 是 ~/.codex/skills/，
用你实际使用的助手为准），装完告诉我这个 skill 怎么触发。

装完怎么用

重启助手后正常对话即可，说需求就会触发，不用记命令。试这几句：

  • 「我是管理学硕士，导师给的题目是企业数字化转型研究，说太大了，帮我缩小并搭一个论文大纲。」
  • 「帮我规划文献综述：先读什么、怎么组织、引注怎么把握。」
  • 「我的方法章只有一句『采用问卷调查法』，帮我改写成能过开题的写法。」

也可以显式点名（如 $thesis-writing-craft 或「用论文写作方法库」）。写完整章后，让它跑一遍 skill 里的成稿自检清单，逐节核对。

边界

  • 这个 skill 用于搭结构、找方法、改表达、核格式；成稿的事实与观点由作者本人核实并定稿。
  • 涉及字数、格式、送审与 AI 使用规定，一律以学校和期刊的最新通知为准。
  • 不写「保证通过」类承诺；检测与送审结果不受任何写作方法保证。
