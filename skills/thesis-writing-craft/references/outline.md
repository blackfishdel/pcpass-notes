# 大纲与结构

先分清两件事：**目录是章节标题的清单，大纲是每章「写什么、怎么论证」的作战计划**。导师说「先搭大纲」，指的是后者。

## 第一步：选写作范式，再套骨架

不同研究类型的大纲长得不一样。先判断论文属于哪一类，再对号入座（骨架来自高校官方写作范式文件，见来源 1）：

| 范式 | 章节骨架 |
| --- | --- |
| 实证研究 | 引言（背景与问题 / 国内外研究回顾 / 目的与意义 / 方法与思路）→ 理论基础与研究假设 → 研究设计与数据说明（测量工具 / 数据来源 / 信效度检验）→ 数据分析与结果（描述统计 / 假设检验）→ 结论与启示 → 参考文献 |
| 实验研究 | 引言 → 相关研究评述与假说（含中介/调节）→ 研究设计（被试与程序 / 操纵与变量 / 实验材料）→ 实验结果（操纵有效性检验 / 描述统计与相关分析 / 假设检验 / 稳健性检验）→ 结论与启示 |
| 质性研究（扎根理论） | 引言 → 文献回顾与评述（国内 / 国外 / 评述）→ 研究设计（方法论立场 / 理论抽样 / 数据收集）→ 数据分析（开放编码 / 主轴编码 / 选择编码 / 理论饱和度检验）→ 结论与启示 |
| 问题对策型 | 引言（背景及意义 / 研究回顾 / 研究问题）→ 相关概念及理论 → 问题分析（**现状与问题要有数据佐证**：问卷 / 管理工具 / 现状与标准对比）→ 对策与建议（**针对原因，而非问题**）→ 结束语 → 参考文献 |

判断不出来就问用户「你的数据是问卷/实验/访谈，还是拿企业问题做对策」，按答案选。

## 五章制与字数配比（应用型 / 问题对策型模板）

管理类、应用型、问题对策型论文的五章制与篇幅重心（配比来自开源 MBA 论文写作指南，见来源 2；具体比例以本校模板为准）：

| 部分 | 篇幅 | 内容要点 |
| --- | --- | --- |
| 摘要 | 800–1500 字 | 背景 / 问题 / 方法 / 结论；关键词 3–5 个 |
| 第 1 章 绪论 | 约 10–15% | 研究背景（宏观→企业→具体问题）· 目的与意义 · 文献述评（**按主题分类 + 指出缺口，不是作者排队**）· 内容与方法 · 技术路线 |
| 第 2 章 相关理论 | 约 15–20% | 核心概念（2–3 个）· 理论（观点 + 本文怎么用）· 理论在本研究中的分析框架 |
| 第 3 章 现状及问题 | 约 15–20% | 业务边界 · 现状（数据、流程、对比）· 问题 2–3 个（不超过 5 个）· 成因（用第 2 章框架分析） |
| 第 4 章 方案设计 | 约 25–30%（篇幅重心） | 原则与目标 · 总体思路（与成因对应）· 对策一/二/三 · 预期效果 |
| 第 5 章 实施保障 | 约 15–20% | 组织/制度/资源 · 分阶段计划 · 风险与评估 |
| 结论 | 约 5–10% | 发现 / 不足 / 边界 / 展望 |

配套两条硬规则：

- **题目公式**：应用/问题对策型用 [XX 公司/群体] + [XX 问题] + [研究 / 优化 / 设计]；实证型用 [具体群体] + [X 对 Y 的影响] + [情境]（与 topic-narrowing.md 的三层限定结果一致）。
- **一一对应对照表**：问题对策型核对「3.3 问题 ↔ 4.3 对策」，第 3 章列出的每个问题在第 4 章必须有针对其成因的对策；实证型核对「2.x 假设 ↔ 4.x 检验」，每条假设都有对应的检验结果。缺对应就删或补。这张表交稿前要真的画出来核对一遍。

## 实证型论文怎么定篇幅

上面的配比表属于应用/问题对策型。实证型（问卷、实验、二手数据）按其骨架组织，**篇幅重心放在数据分析与结果章**，引言与综述合计一般不超过全文三分之一；具体比例以本校模板和同院近三年同范式论文为准，没有官方配比就照「方法与结果两章最厚」的原则分配，不要照搬上表。

## 沙漏模型（检查整体结构的尺子）

学术论文整体呈沙漏形（见来源 3）：

- 引言从宽处切入，交代大背景；
- 中段（综述、方法、结果）收窄到本研究的细节；
- 结论再放宽，讨论发现的意义与边界。

用法：写完初稿后从头到尾扫一遍——引言是否「由面到点」收进本研究？结论是否回到了更大的意义而不是重复结果？引言里提出创新点时避免夸大重要性。

## 三级标题怎么定

- 一级标题 = 章（研究阶段）；二级标题 = 该阶段要回答的问题；三级标题 = 问题的拆解面，不再往下细分。
- 每个二级标题应能补成一句完整的话（如「3.2 库存周转为什么慢」），补不出来的说明切分维度混了。
