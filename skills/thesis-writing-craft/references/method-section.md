# 研究方法章

方法章的任务：**详细描述每一个步骤和决策及其原因**，让读者能判断（甚至复现）你怎么得到结果。写「做了什么 + 为什么这么做」，不写流程套话。

## 五条硬要求（来源 1）

1. 先论证方法的**适用性和严谨性**：所选方法为什么能有效回答研究问题。
2. 清晰说明**数据收集与分析过程**：样本选取、测量工具、分析方法、缺失数据处理策略。
3. **透明报告研究局限**及其对结果的可能影响。
4. 引用量表须标**来源与信效度**。
5. 写明**研究限制与伦理**：时间、人力、受试者保护。

## 推荐的章节顺序（来源 2）

研究设计（质性/量化/混合 + 选择理由与流程）→ 研究对象与样本（抽样方式、样本数、代表性）→ 资料收集工具（问卷/访谈/实验）→ 资料分析（统计或质性分析软件与步骤）→ 研究限制与伦理。

## 四类范式的方法章各写哪几块（来源 3）

| 范式 | 方法章必须覆盖 |
| --- | --- |
| 实证 | 测量工具选择 → 数据来源 → 数据可靠性与有效性（信度、效度、共同方法偏差检验） |
| 实验 | 被试与实验程序 → 实验操纵与变量测量（实验材料）→ 操纵有效性检验 → 假设检验 → 稳健性检验 |
| 质性（扎根） | 方法论立场 → 理论抽样 → 数据收集 → 三级编码（开放/主轴/选择）+ 理论饱和度检验 |
| 问题对策 | 问题从问卷、管理工具或「现状与标准对比」中**有数据佐证**地得出；对策**针对原因而非问题** |

## 写法示例

差的写法：「本研究采用问卷调查法，对数据进行了统计分析。」——没有信息量。

好的写法：「本研究于 2026 年 3–4 月向珠三角 3 家中小制造企业的生产与计划岗位发放问卷，回收 217 份、有效 198 份（有效率 91.2%）。生产效率用人均产出（件/班次）测量，数据取自企业 MES 系统导出的月度汇总；因变量、自变量分别来自问卷不同部分以降低共同方法偏差。缺失值处理：单题缺失率 <5% 的用均值替代，其余做删除，样本量变化在各分析处注明。」

区别在：每一步都有**数字、工具名、时间范围、决策理由**，读者能核对。
