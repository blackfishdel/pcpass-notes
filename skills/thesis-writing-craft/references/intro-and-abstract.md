# 引言、摘要与关键词

## 引言三段式（中文学位论文通用）

开门见山，用带标题的三大节交代清楚（来源 1）：

- **1.1 研究背景与意义**，逻辑链：宽的问题 → 重要性 → 窄的问题 → 需求及其重要性 → 术语解释 → 目前离需求的距离 → 研究主题 → 研究主题对宽问题的价值 → 过渡到研究现状。
- **1.2 研究现状**：围绕需求介绍研究历史、里程碑工作、最新动态；最后指出与 1.1 需求之间的差距、遗留问题或启发。
- **1.3 本文安排**：一句话回顾需求 + 遗留问题 → 列出本文要研究的内容 → 目标与思路 → 余下章节安排。

开场给一句针对论文主题的概述（标题的扩充版），并预告下文分三节展开。三节要逻辑关联、前后呼应、过渡自然。

## 国际期刊视角的四技巧（Elsevier 作者服务，来源 2）

1. **定位细分领域**：从概括性陈述循序渐进过渡到细分领域（由面到点）。
2. **直奔主题、减少铺垫**：开头就给与研究主题相关的必要信息，不要「制造悬念」。
3. **阐释重要性**：从「本研究意图填补的空白」入手，解释结果的意义。
4. **概述趋势**：适当描述主题的历史进程，通过文献综述引出关键突破。

引言避免过分夸大研究重要性（来源 3）。

## 摘要 vs 引言：分工别混

| | 摘要 | 引言 |
| --- | --- | --- |
| 位置 | 正文前，独立成篇 | 正文开头，紧随摘要 |
| 任务 | 概述全文：目标、方法、结论、创新性、相关性 | 交代背景 → 综述既有发现 → 过渡到空白 → 说明本研究如何填补 |
| 篇幅 | 一般不超过论文总字数的 10% | 按学校/期刊要求 |
| 形式 | 分段式（背景/方法/结论小标题）或单段式，按期刊要求选 | 三段式（见上） |

（来源 4）

**摘要写作逻辑**：介绍研究主题 → 说明选择原由 → 提出假设 → 展示结果；收尾有力；核对数据准确性。

**关键词**：3–5 个，从题名与摘要中提取能被检索到的实义词，不用过于宽泛的词。

## 常见错误

- 摘要写成引言的缩写（缺方法与结果的具体信息）。
- 引言「制造悬念」压着研究问题不放，评委会失去耐心。
- 引言堆砌与本研究无直接关系的背景（违反「重质量不重数量」，见 literature.md）。
