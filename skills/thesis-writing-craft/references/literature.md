# 文献：查找、阅读、整理、写综述

## 一、查找：六步检索路线

高校图书馆官方给新手的路线（来源 1）：

**想清楚要找什么 → 准备关键词 → 开始检索 → 缩小结果 → 阅读与追踪 → 规范引用**

要点：

- 入口分校园网内 / 校外（统一身份认证、VPN 或图书馆校外访问），**入口和权限因校而异，认准本校图书馆说明**。
- 检索范围做减法：只想找中文期刊，就先关掉其他文献类型；CNKI 覆盖期刊、学位论文、会议、报纸、图书。

检索不到东西，多半不是数据库的问题，而是关键词没积累够（来源 2）：

- **先读综述再读研究性论文**：综述给领域现状、热点、潜在方向。
- 前期从综述里记关键词、看引文题目里反复出现的词，攒够词再上数据库。
- 善用引文：新综述的参考文献已被归纳分析过，质量往往高于自己盲检。

快速摸清一个领域的调研三步法（S. Keshav，ACM SIGCOMM CCR 2007，来源 3）：

1. 用学术搜索引擎找出 3–5 篇相关领域近期最高引用的论文，读其 related work；
2. 在这些论文的参考文献里找**共同引用的论文、重复出现的作者**，访问关键人物主页看近期发表；
3. 访问顶级会议网站，浏览最近会议记录，快速筛高质量相关工作。
4. 汇总第 1、2 步的高引论文，即文献综述的初版；三步可迭代。

## 二、阅读：三遍法 + 筛选漏斗

**三遍阅读法**（S. Keshav「How to Read a Paper」，来源 3、4）：

| 遍数 | 时长 | 怎么读 | 读完要能 |
| --- | --- | --- | --- |
| 第一遍 | 5–10 分钟 | 标题、摘要、引言 → 只读各级小标题 → 有数学先看理论基础 → 读结论 → 浏览参考文献 | 回答 5C：类别（Category）、背景（Context）、正确性（Correctness）、贡献（Contributions）、清晰度（Clarity） |
| 第二遍 | 约 1 小时 | 仔细看图表（坐标轴是否标对、结论是否有统计意义），不纠结推导细节，标记未读过的参考文献 | 用几句话总结全文主旨 |
| 第三遍 | 重构 | 跟随作者思路在脑中重现论文，与原文比较，逐条挑战作者假设 | 找出创新点、隐含假设、潜在问题与引文缺失 |

**三层筛选漏斗**（来源 5）：不要每篇都全文精读。

- 第一层：标题与摘要，5–10 秒判断相关性；
- 第二层：引言、图表与结论，5–10 分钟判断价值；
- 第三层：全文精读，只对通过前两层、约占总数 10–20% 的核心文献投入大量时间。

三种阅读目的对应三种读法（来源 5）：前沿追踪式（顶刊标题/摘要/图表扫读）、问题驱动式（围绕具体问题系统检索对比）、经典奠基式（读奠基论文）。

**精读六问**（研究性论文，来源 2）：作者做了什么 / 做这件事有什么意义 / 用什么方法 / 方法每一步具体怎么操作、目的是什么 / 有哪些难点、作者如何解决 / 每张图每张表每个结果说明什么问题。六问答完，一篇文献算读懂，且研究方案的雏形会顺带出来。

## 三、整理：综述四步 + 结构化笔记

综述四步（来源 6）：**收集 →（用数据库搜关键词）→ 分类（按研究主题、样本或理论架构，建表格或心智图）→ 评析（指出各研究优缺点与缺口，为本研究定位）→ 整合（每小节结尾连回自己的研究问题）**。文献探讨是撑起整篇论文的柱子，不是装饰。

结构化精读笔记模板（来源 7），每篇核心文献一张：

- 基本信息：作者 / 年份 / 来源 / 主题 / 链接
- 一句话摘要：研究谁、用什么方法、得到什么结论
- 研究对象与核心问题
- 研究方法：类型（理论/实证/实验/案例/混合）、总体思路、为什么用这种方法、分析单位、关键变量、具体步骤、优势与局限
- 数据来源：类型 / 样本来源 / 时间范围 / 样本量 / 局限
- 研究结论：主要发现 + 原文引用 + 页码成对记录
- 我的判断：最有启发的点 / 可借鉴的方法 / 可继续追问的问题 / 与我的研究关联

文献管理软件按任务选，不按 star 数选（来源 8、9）：写作插件兼容性（Word / WPS）、能否导入知网 / CAJ、能否输出 GB/T 7714 国标格式，是中文场景的必测项；Zotero 免费、可浏览器抓取知网页面、免费同步空间 300M，NoteExpress 对中文数据库支持好（注意：两者功能对比来自厂商官网自述，采信前自行实测）。

## 四、写综述：组织方式与引注规范

- **按研究假设的顺序组织**，而不是按作者或年份排队（来源 3）。
- **重质量不重数量**：只回顾与主题直接相关的文献；批判性分析先前研究的发现、方法和理论框架，指出缺口，避免简单复述（来源 3）。
- 综述的合理形态（来源 10）：为提出问题而做的综述（引言里）、通篇以综述性方法为主的研究——这两种规范；正文各处大量堆他人数据观点、实质是综述性论文冒充研究——不规范。
- **引注以必要为限**（来源 10）：有论文 2 万字但引文占 30%–50%，去掉引文就大幅缩水，属不合理综述。好的综述用于追踪动态、展示前沿、指出缺口。
- 方法上可选最佳证据综合法、批判性综述、元分析等（来源 10），按学科惯例选。
