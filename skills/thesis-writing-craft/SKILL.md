# 论文写作方法库

帮用户把论文的每一节写成「有观点、有证据、可执行」的成稿，而不是名词与政策的罗列。全部方法来自公开可查的来源（高校图书馆指南、高校官方写作范式文件、ACM 经典论文、期刊出版社作者服务），出处标在各 reference 末尾。

## 使用边界

- AI 辅助的范围：搭结构、找方法、改表达、核格式。事实与观点由作者本人核实并定稿。
- 涉及学校或期刊的规则（字数、格式、送审要求、AI 使用规定）一律提醒用户「以学校/期刊最新通知为准」，不要替学校下结论。
- 不写「保证通过」「保证过线」类承诺。

## 工作流

1. 先弄清三件事：论文类型（本科毕业论文 / 硕士学位论文 / 课程论文）、学科、当前卡在哪一步。用户没说就问。
2. 按任务读对应的 reference，读一个用 一个，不要全部加载：

| 用户在做的事 | 读 |
| --- | --- |
| 定结构、搭大纲、分配各章字数 | [references/outline.md](references/outline.md) |
| 找文献、读文献、写文献综述 | [references/literature.md](references/literature.md) |
| 写引言、摘要、关键词 | [references/intro-and-abstract.md](references/intro-and-abstract.md) |
| 写研究方法章 | [references/method-section.md](references/method-section.md) |
| 选题太大、找不到创新方向 | [references/topic-narrowing.md](references/topic-narrowing.md) |

3. 写任何一节都遵守下面的通用守则；整章写完跑「成稿验证」。

## 通用写作守则（每一节都适用）

1. **三要素**：观点（一个判断）、案例（一个可对照的具体例子）、可执行解法（读者今天就能照着做的动作）。三者缺一的节视为空洞，重写而不是润色。
2. **每节自检三问**：读者今天能照着做什么？数字是多少？做错了会怎样？任何一问答不上来就先补内容。
3. **每节至少 1 个可核验的具体物**：数字、字段名、文号、量表名、样本量、时间范围——任一即可。通篇「具有重要意义」式表述的节不合格。
4. **一一对应**：问题对策/应用型论文里，写了问题一就必须有针对其成因的对策一，附「问题 ↔ 对策」对照表；实证型论文同理，写了假设 H1 就必须有对应的检验结果，附「假设 ↔ 检验」对照表。对不上就删掉或补齐。
5. **大题先化小再动笔**：题目宽到文献看不完时，先做三层限定（研究对象 → 核心变量 → 场景），见 topic-narrowing.md。

## 事实与引注规范

- 每条事实可回溯：写进正文前能说出它来自哪篇文献或哪个官方页面；说不出来源的信息不写成事实，宁可删掉。
- 引用写全：作者、出处（期刊或机构）、年份；网络资料记 URL 与查看日期。
- 引用以必要为限：引文成段、占全文比例过高时，改为用自己的话评析后挂引注；综述是「评析 + 整合」，不是摘要排队。
- 数据、规则、标准类表述加「以学校/期刊最新通知为准」。

## 成稿验证（整章写完必跑）

逐节过一遍，任何一条不过就回去改：

- [ ] 每节能通过自检三问
- [ ] 每节至少 1 个可核验的具体物（数字/字段名/文号/样本量）
- [ ] 一一对应对照表完整（问题↔对策，或假设↔检验），无孤儿项
- [ ] 所有事实能回溯到来源；未核实内容已删除或明确标注「待核实」
- [ ] 引注密度合理，无成段引文
- [ ] 各章字数配比符合所选大纲范式（见 outline.md 的配比表）
- [ ] 规则类表述带「以学校/期刊通知为准」
